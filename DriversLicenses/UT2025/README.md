# Dataset: Utah Driving Priviledge Cards Issuance and Renewal Data

## Overview
This dataset contains issuance and renewal data for Utah's Driving Priviledge Card program introduced with Utah SB 227.

## Contents
January 2005 - November 2025 Monthly Data (n = 251)
- Issuances
- Renewals

## Format
UT2025_Combined.CSV

```
Date,Original,Renewal
2005-01,9,2
2005-02,17,14
2005-03,99,18
2005-04,83,23
```

## Source
The data was obtained under a GRAMA request submitted to the Utah Department of Public Safety in December 2025.

## Notes
- A December 2025 value is included but incomplete.
