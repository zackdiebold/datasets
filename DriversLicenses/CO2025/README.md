# Dataset: Colorado SB251 License Issuance and Renewal Data

## Overview
This dataset contains monthly issuance and renewal data for driver's licenses and renewals issued under Colorado SB 251 (The Colorado Road and Community Safety Act).

## Contents
January 2018 - November 2025 Monthly Data (n = 95)
- Issuances
- Renewals

## Format
CO2025_Combined.CSV

```
Date,Original,Renewal
2018-01,345,2371
2018-02,304,1665
2018-03,320,1814
2018-04,293,1712
```

## Source
The data was obtained under a CORA request submitted to the Colorado Department of Revenue in December 2025.

## Notes
- The March 2020 Issuances data point is NA.
